# الاستوديو التعليمي

أداة تعمل داخل المتصفح لبناء دروس مرئية: مقدّم متحرك، ولوحات هولوغرافية، وعرض مسموع.
افتح `index.html` في المتصفح لتشغيلها (الأفضل عبر GitHub Pages ليجد مجلد `frames/`).

## حركة المقدّم

من تبويب «المقدّم» ← «الحركة» اختر حركة، ثم «معاينة الحركة». تعمل الحركة أثناء «عرض الدرس».

| الحركة | الوصف |
|---|---|
| مشي جانبي / مشي من الخلف | دورة من 8 إطارات، ويمكن جعل المقدّم يمشي عبر المشهد بشريط «المشي عبر المشهد» |
| تحية بالتلويح، يد على الصدر | تحية |
| يشرح بيديه، يقدّم ويعرض | شرح |
| يشير لليمين / لليسار / للأعلى | إشارة |
| يعدّ بالأصابع، انتبهوا، يفكّر، وقوف | أخرى |

## صوت الشرح

من تبويب «المشهد» ← «صوت الشرح المسجّل»: سجّل بالميكروفون (حتى 3 دقائق) أو ارفع ملفًا صوتيًا (mp3 / m4a / wav).
- في «عرض الدرس» يُشغَّل الصوت المسجّل بدل القراءة الآلية، ويتقدّم العرض عند انتهائه.
- في فيديو MP4 يدخل الصوت مع الصورة، ومدة المشهد بطول صوته. المشهد بلا تسجيل يبقى صامتًا.
- يُحفظ الصوت مع المشروع (التسجيل التلقائي وملف المشروع). التسجيل يتطلب فتح الاستوديو عبر https (مثل GitHub Pages).

الحركات تعمل بتبديل إطارات جاهزة مع انتقال ناعم وتنفّس خفيف، وتُحفظ مع المشروع.

## الملفات

| المسار | المحتوى |
|---|---|
| `index.html` | الاستوديو (يحوي قائمة الحركات مدمجة) |
| `frames/` | إطارات الحركة (WebP شفاف، بمقياس موحّد) و `manifest.json` |
| `tools/build_frames.py` | يبني `frames/` من `poses/` ويحدّث قائمة الحركات داخل `index.html` |
| `poses/` | صور المصدر الأصلية (معظمها وضعيتان في صورة) |

لإعادة البناء بعد تعديل الصور أو الحركات: `python3 tools/build_frames.py` (يحتاج Pillow و numpy و scipy).

## مكتبة الوضعيات (`poses/`)

| المجلد | المحتوى | عدد الصور |
|---|---|---|
| `poses/actions/` | إشارة للأعلى، قفز، ضحك وتشجيع | 3 |
| `poses/gestures/` | تحية، إشارات، شرح، تفكير، عدّ بالأصابع | 17 |
| `poses/sitting/` | وضعيات الجلوس | 3 |
| `poses/emotions/` | خجل، حزن، تعب | 4 |
| `poses/walk-run/` | مشي وجري (جانبي، أمامي، من الخلف) | 10 |
| `poses/turnaround/` | زوايا الشخصية (أمام، جانب، خلف) | 4 |

ملاحظة: خلفية صور `poses/` بيضاء وليست شفافة، وصورة `walk-side-glow` عليها توهج داكن.
