# الاستوديو التعليمي

أداة تعمل داخل المتصفح لبناء دروس مرئية: مقدّم، ولوحات هولوغرافية، وعرض مسموع.
افتح `index.html` في المتصفح لتشغيلها.

## مكتبة الوضعيات (`poses/`)

صور للمقدّم يمكن استخدامها عبر «رفع PNG شفاف» أو من تبويب «تحريك». معظم الصور تحوي وضعيتين في صورة واحدة.

| المجلد | المحتوى | عدد الصور |
|---|---|---|
| `poses/actions/` | إشارة للأعلى، قفز، ضحك وتشجيع | 3 |
| `poses/gestures/` | تحية، إشارات، شرح، تفكير، عدّ بالأصابع | 17 |
| `poses/sitting/` | وضعيات الجلوس | 3 |
| `poses/emotions/` | خجل، حزن، تعب | 4 |
| `poses/walk-run/` | مشي وجري (جانبي، أمامي، من الخلف) | 9 |
| `poses/turnaround/` | زوايا الشخصية (أمام، جانب، خلف) | 4 |

## الحركات الجاهزة (`frames/`)

إطارات بخلفية شفافة ومحاذاة للقدمين، مع ملفات تشغيل جاهزة.

| الحركة | الملفات |
|---|---|
| مشي جانبي (8 إطارات، 10 إطارات/ث) | `frames/walk-side/walk-side-01.png` … `08.png`، `walk-side-sheet.png`، `walk-side.gif`، `walk-side.webp` |

ملاحظة: الخلفية بيضاء وليست شفافة، وصورة `walk-side-glow` عليها توهج داكن، فقد تحتاج إزالة الخلفية قبل الاستخدام داخل المشهد.
