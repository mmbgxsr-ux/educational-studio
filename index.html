إدراج الشرح كترجمة

الفيديو 1280×720، ويتضمن الصوت المسجّل أو المرفوع لكل مشهد (المشهد بلا تسجيل يبقى صامتًا لأن المتصفح لا يسمح بتسجيل القراءة الآلية). مدة المشهد بطول صوته. يحتاج Chrome أو Edge أو Safari حديثًا، ويعمل من GitHub Pages لا من فتح الملف مباشرة.

ملف ZIP يضم صورة لكل مشهد، ونص الشرح، وملف المشروع. العرض يعمل داخل المتصفح ولا يُنتج فيديو. احفظ المشروع كملف للاحتفاظ بنسخة كاملة (Ctrl+S).
